# NEF Vorlagen – Hosting des Outlook-Add-ins

Dieses Repository enthält **nur die Web-Dateien** des Outlook-Add-ins «NEF Vorlagen» der Nef Sportwagen AG.
Es wird über GitHub Pages unter `https://csf-ag.github.io/nef-vorlagen/` ausgeliefert. Outlook lädt die Dateien beim Klick auf die Buttons von dort.

- Betreuung: CSF Computer Solutions Facility AG
- Projekt, Skripte, Tests und Anleitung liegen im privaten Repository `CSF-AG/NEF-AddIn`.

**Bitte keine Dateien umbenennen oder verschieben.** Das Manifest in Microsoft 365 verweist auf genau diese Pfade.
Text, Empfänger oder Betreff einer Vorlage ändert man nur in `templates.js`.
